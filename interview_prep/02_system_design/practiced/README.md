# Practiced Designs — your own workspace

> This is **your** scratch folder. The `../classic_designs/` and `../project_designs/` files are *reference solutions*.
> The learning loop that actually works: **design it yourself here first (45 min, from blank), then diff against the reference.**
> The gap you find is your real study list.

## How to use
1. Pick a design from the rotation below.
2. Run your own [framework](../framework.md) cold — requirements → estimate → API → data model → architecture → deep dive → bottlenecks.
3. Write your full pass into the matching file here.
4. Open the reference solution and note every point you missed.
